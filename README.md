# Traffic Congestion Prediction using Machine Learning

## Project Overview
This project uses machine learning to predict traffic congestion levels based on traffic and environmental data. It explores data preprocessing, exploratory data analysis (EDA), and classification models using Python and scikit-learn.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn

## Dataset
The dataset is hosted on Google Drive because the CSV file exceeds GitHub's regular upload limit.

## Models
- K-Nearest Neighbors (KNN)
- Gaussian Naive Bayes
- Multinomial Naive Bayes
- Bernoulli Naive Bayes
- Decision Tree Classifier
- Random Forest Classifier
